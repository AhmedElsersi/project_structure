# Folder structure

The annotated tree of `flutter_template/`, what goes where, and the naming rules. Layer rules and
diagrams are in [ARCHITECTURE.md](ARCHITECTURE.md).

```
flutter_template/
├── .env.example                 committed template of .env (compile-time config); .env / .env.* are gitignored
├── .github/workflows/ci.yml     format · locale keys up to date · check_translations · analyze --fatal-infos · test
├── analysis_options.yaml        strict analyzer + lints (markspulse set + avoid_print), page width 120
├── pubspec.yaml                 dependencies (docs/PACKAGES.md), assets
├── android/                     app/build.gradle.kts reads key.properties for release signing; manifest has
│                                INTERNET + CAMERA + url_launcher <queries>
├── ios/                         Podfile permission macros; Info.plist usage strings, CFBundleLocalizations ar/en,
│                                LSApplicationQueriesSchemes
├── assets/
│   ├── translations/ar.json     Arabic (start locale) ┐ same keys, real text in both;
│   ├── translations/en.json     English (fallback)    ┘ LocaleKeys generated from them
│   ├── mocks/app_config.json    GET /app-config fixture (mock backend)
│   ├── mocks/items.json         sample feature seed data
│   └── images/                  app images (add fonts/ here too, and branding/ for icon + splash sources)
├── lib/                         see below
├── test/                        see below
└── tool/                        see below
```

### What goes where

| You are adding | Put it in | Notes |
|---|---|---|
| A screen, cubit, model or API call for one business area | `lib/features/<feature>/...` | Start with `dart run tool/create_feature.dart <feature>` |
| A widget used by **one** feature | `lib/features/<feature>/presentation/widgets/` | Promote it to `shared/` only when a second feature needs it |
| A widget used by **two or more** features | `lib/shared/widgets/<group>/` | Takes translated strings and theme-only styles; document it in `docs/WIDGETS.md` |
| An app-level screen (not owned by a feature) | `lib/shared/screens/` | |
| A plugin wrapper or app-wide service | `lib/core/services/` (interface + implementation) | Register it in `services_module.dart` |
| An extension, formatter or pure helper | `lib/core/utils/` or `lib/core/extensions/` | Plus unit tests |
| A design token or theme change | `lib/core/theme/` | Colour literals live only here |
| A persisted key | `lib/core/storage/storage_keys.dart` | Add it to `deviceScoped` if it must survive sign-out |
| An app-level endpoint | `lib/core/network/api_endpoints.dart` | Feature endpoints go in the feature's data source (`ItemsEndpoints`) |
| An environment variable | `.env.example` + `lib/core/config/app_env.dart` | |
| Translations | `assets/translations/{ar,en}.json` under `<feature>.*` | Then `./tool/gen_locale_keys.sh` |
| Mock data | `assets/mocks/<feature>*.json` + `data/mock/<feature>_mock_api.dart` | |
| Fonts, brand images | `assets/fonts/`, `assets/images/`, `assets/branding/` (icon/splash sources) | Declare fonts and images in `pubspec.yaml` |

## tool/

| Script | Run | Does |
|---|---|---|
| `create_feature.dart` | `dart run tool/create_feature.dart <name> [--use-cases]` | Scaffolds `lib/features/<name>/` (entity, repository interface, model, data source + endpoints, mock API, repository impl, `DataCubit`, screen, routes, DI; `--use-cases` adds `domain/use_cases/get_<name>_use_case.dart`). Adds `<name>.title` to both JSON files. Refuses to overwrite. Prints the `main.dart` / `app_router.dart` lines |
| `rename_app.dart` | `dart run tool/rename_app.dart --package <pkg> --name "<Display Name>" --id <application.id> [--dry-run]` | Renames package, display name and app ids everywhere (see [NEW_PROJECT_CHECKLIST.md](NEW_PROJECT_CHECKLIST.md#1-copy-and-rename)) |
| `check_translations.dart` | `dart run tool/check_translations.dart` | Fails on: a key in one locale only, empty values, placeholder or plural-form mismatch, `Text('literal')` in `lib/`, `.tr()` on an unknown key |
| `json_credential.dart` | `dart run tool/json_credential.dart <ENV_VAR> [--env-file .env]` | Resolves a JSON credential given as a path or base64, and prints metadata only ([SERVICES.md#jsoncredential](SERVICES.md#jsoncredential)) |
| `gen_locale_keys.sh` | `./tool/gen_locale_keys.sh` | Regenerates `lib/core/localization/generated/locale_keys.g.dart` |

Tools are pure Dart (`dart run`, no Flutter imports), so CI can run them without a device.

## Naming rules

| Rule | Example |
|---|---|
| Files and folders are `snake_case` | `item_details_screen.dart` |
| **One public widget per file**, named after it (private `_Helpers` may share the file) | `item_tile.dart` → `ItemTile` |
| Screens: `<name>_screen.dart` → `<Name>Screen` | `items_list_screen.dart` → `ItemsListScreen` |
| Cubits: `<name>_cubit.dart`; custom states: `<name>_state.dart` (in `presentation/managers/`) | `create_item_cubit.dart`, `create_item_state.dart` |
| Feature DI: `<feature>_di.dart` → `register<Feature>Feature()` | `items_di.dart` → `registerItemsFeature()` |
| Feature routes: `<feature>_routes.dart` → `abstract final class <Feature>Routes` | `ItemsRoutes.details(id)` |
| Data sources: `<name>_remote_data_source.dart` (+ `<Name>Endpoints`) | `ItemsRemoteDataSource`, `ItemsEndpoints.items` |
| Models: `<name>_model.dart` → `<Name>Model` with `fromJson` / `toEntity` | `ItemModel` |
| Repositories: interface `<name>_repository.dart`, impl `<name>_repository_impl.dart` | `ItemsRepository`, `ItemsRepositoryImpl` |
| Use cases: `<verb>_<noun>_use_case.dart` → `<Verb><Noun>UseCase` with `call(...)` | `CreateItemUseCase` |
| Mock API: `data/mock/<feature>_mock_api.dart` → `register<Feature>MockApi(mock)` | `registerItemsMockApi` |
| Tests: same path under `test/` + `_test.dart` | `test/features/sample_feature/items_list_cubit_test.dart` |
| Translation keys: `<feature>.<snake_key>` → `LocaleKeys.<feature>_<snake_key>` | `items.empty_title` → `LocaleKeys.items_empty_title` |
| Route paths: lowercase, kebab-case segments, ids as `:param` | `/order-history/:id` |
| Generated files end in `.g.dart` and are never edited by hand | `locale_keys.g.dart` |

The folder name of a feature (`sample_feature`) may differ from its file prefix (`items_`). New
features from `create_feature.dart` use the same name for both.
